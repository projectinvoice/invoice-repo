🚀 Démarrage

Comment créer mon compte entreprise ?
Cliquez sur « Essai gratuit » depuis la page d'accueil, renseignez le nom de votre entreprise, votre email et un mot de passe. Un email d'activation vous sera envoyé — cliquez sur le lien qu'il contient pour finaliser la création du compte.
Je n'ai pas reçu l'email d'activation, que faire ?
Vérifiez vos courriers indésirables (spam). Si vous ne le trouvez toujours pas, utilisez le lien « Renvoyer l'email d'activation » disponible sur la page de connexion.
Comment configurer les informations de mon entreprise (logo, coordonnées) ?
Rendez-vous dans « Paramètres de l'entreprise » depuis le tableau de bord une fois connecté : vous pourrez y ajouter votre logo, votre adresse et vos coordonnées, qui apparaîtront sur vos factures PDF.

🧾 Ventes & factures

Comment enregistrer une vente ?
Depuis la section « Ventes », cliquez sur « Ajouter ». Sélectionnez un client existant ou créez-en un nouveau directement depuis le formulaire, ajoutez les produits vendus, puis choisissez le mode de paiement : comptant, crédit ou avance.
Quelle est la différence entre paiement comptant, crédit et avance ?
Comptant : le client paie la totalité immédiatement. Crédit : rien n'est payé à la vente, une date d'échéance est fixée pour le règlement total. Avance : le client verse une partie du montant, le solde restant est dû à une date d'échéance donnée.
Une facture est-elle générée automatiquement ?
Oui, dès qu'une vente est créée, une facture est automatiquement générée avec un numéro unique et séquentiel. Vous pouvez la télécharger en PDF ou enregistrer des paiements complémentaires depuis la section « Factures ».
Que se passe-t-il si je supprime une vente ?
Les quantités vendues sont automatiquement recréditées dans votre stock.

📦 Stock & approvisionnements

Comment ajouter du stock pour un produit ?
Créez un approvisionnement depuis la section « Approvisionnements » en indiquant le fournisseur et les quantités reçues : votre stock est mis à jour automatiquement.
Comment fonctionne le stock des vendeurs terrain ?
Vous pouvez charger une quantité de produits depuis votre stock magasin vers un agent (« Chargements »). L'agent vend depuis son propre stock personnel, et peut retourner les invendus, qui reviennent alors dans le stock magasin.

🧑‍💼 Espace vendeur

Comment un agent se connecte-t-il à son espace ?
Depuis la page « Connexion vendeur », l'agent renseigne le code de son entreprise ainsi que son code PIN personnel, définis lors de sa création dans la section « Agents ».
Un agent peut-il créer un nouveau client pendant une vente ?
Oui, directement depuis le formulaire de vente terrain, sans avoir à quitter l'écran de vente.

💳 Abonnement & compte

Comment changer mon mot de passe ?
Depuis votre espace connecté, rendez-vous dans les paramètres de votre compte. Vous pouvez aussi utiliser « Mot de passe oublié » depuis la page de connexion si vous n'y avez plus accès.
Comment supprimer mon compte ?
Une option de suppression de compte est disponible dans les paramètres. Cette action est définitive et supprime l'ensemble de vos données.
